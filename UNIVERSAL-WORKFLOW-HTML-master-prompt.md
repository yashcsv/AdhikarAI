# MANDATORY DIAGRAM TYPES

Current prompt must support more than Mermaid sequence diagrams.

Use the most appropriate diagram type for the workflow.

Supported diagram types:

* Sequence Diagram
* Flowchart
* State Diagram
* ER Diagram
* Journey Diagram
* Architecture Diagram
* C4 Context Diagram
* C4 Container Diagram
* Decision Tree
* Dependency Graph

Diagram selection rules:

* Use Sequence Diagram when systems or actors interact in time order.
* Use Flowchart when decision logic dominates.
* Use State Diagram when lifecycle transitions matter.
* Use ER Diagram when entities and relationships matter.
* Use Journey Diagram when user experience or handoffs matter.
* Use Architecture Diagram when system structure matters.
* Use C4 Context Diagram when external systems and boundaries matter.
* Use C4 Container Diagram when services, apps, and infrastructure containers matter.
* Use Decision Tree when branching logic is central.
* Use Dependency Graph when workflows are interconnected or hierarchical.

Use diagrams strategically, not mechanically.

Each workflow must use the best visualization for its actual logic.
