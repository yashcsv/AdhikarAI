# AdhikarAI

Production-grade modular RAG system scaffold.

## Status

This repository currently contains only structure and placeholder files.
No business logic has been implemented yet.

## Tech Stack

- Backend: FastAPI (Python)
- Frontend: React + Tailwind CSS
- Architecture: Clean architecture with modular RAG pipeline components

## Top-Level Structure

```text
AdhikarAI/
	backend/
	frontend/
	data/
	configs/
	scripts/
	requirements.txt
	.env.example
```

## Backend Modules

- ingestion/
- indexing/
- retrieval/
- reranker/
- llm/
- evaluation/
- observability/

## Quick Start (Scaffold Phase)

1. Create and activate a Python virtual environment.
2. Install dependencies from requirements.txt.
3. Copy .env.example to .env and update values.
4. Start implementing module logic incrementally.

## Notes

- Existing data files under data/ are preserved.
- All generated files are placeholders by design.
