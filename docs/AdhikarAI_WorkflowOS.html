AdhikarAI System Overview

A production-grade, RAG-based grounded AI assistant engineered specifically for Indian Labour Law. The architecture prioritizes compliance, explicit source citation, and robust fallback mechanisms in low-resource (CPU-only) environments.

Primary Engine

Hybrid RAG

Dense (FAISS) + Sparse (BM25) with Cross-Encoder reranking.

Infrastructure

FastAPI + React

Modular python backend utilizing SSE streaming and local embeddings.

Guardrails

Strict Fallbacks

Forces "Insufficient Context" mode if retrieval confidence is low.

End-to-End Chat Workflow

RAG Pipeline Architecture

orchestrator.py

The core execution path transforms a user query into a legally grounded response. It enforces strict token limits and applies cross-encoder reranking to ensure high precision before hitting the LLM generation layer.

sequenceDiagram autonumber participant U as User (Frontend) participant O as Orchestrator (FastAPI) participant R as Hybrid Retrieval (FAISS+BM25) participant CE as Reranker (Cross-Encoder) participant L as LLM Provider (Gemini) U->>O: POST /api/chat/stream {query, session} O->>O: Inject Conversation Memory O->>R: Search (alpha=0.6, top_k=7) R-->>O: Return merged dense/sparse chunks O->>CE: Rerank Candidates CE-->>O: Scored & sorted chunks O->>O: Construct Prompt (Lawyer/Normal mode) alt Context Score < Threshold O-->>U: SSE: Fallback "Not enough info..." else Sufficient Context O->>L: Generate stream (Tokens: 800/1800) loop Stream Processing L-->>O: text delta O-->>U: SSE: data: {"type": "delta"} end O->>O: Calculate Confidence (Clamped 65-93%) O-->>U: SSE: data: {"type": "final", metadata} end

Trigger & Inputs

  • Trigger: User submits prompt via UI.
  • State mode: "Lawyer" (Professional), "Normal" (Plain language).
  • Thinking: On (1800 tokens) vs Off (800 tokens).

Output & Final State

  • Format: A structured layout enforcing A) Direct Answer, B) Legal Basis, C) Practical Steps, D) Caveats.
  • Telemetry: Latency metrics, confidence score, and chunk hit-rates attached to final SSE payload.

Engineering Decisions:

Chunking respects legal boundaries by attempting to split along Section or Chapter patterns. CPU embedding is utilized over GPU processing to ensure wide deployability on minimal infrastructure.

EX-01

Failure Engineering & Resilience

AdhikarAI prioritizes explicit handling of "unhappy paths". The system implements graceful degradation mechanisms rather than outright crashes.

LLM Quota or Auth Failure

Provider limits reached (429) or invalid API keys.

Fallback to Local Mock Response (Uses raw retrieved chunks to construct a deterministic draft without an LLM).

Cross-Encoder OOM / Crash

Memory limits exceeded when running MS-MARCO.

Failsafe triggers Embedding Cosine Fallback (all-MiniLM) for reranking.

Insufficient Context Identified

Retrieval confidence score drops below 0.12 baseline.

Hard abort before generation. Emits: "Not enough information in the provided legal documents."
